## 소켓 규약 — 실제로 해보고 알게 된 것

| | |
| --- | --- |
| 이름 | `socket_head` · `socket_back` · `socket_neck`. 없으면 `head`·`torso`·`spine` 등으로 대체 탐색 |
| **높이를 숫자로 박으면 안 된다** | Kenney 는 `head` 뼈가 **목 근처**에 있다. 다른 팩은 정수리에 있다. 숫자를 박으면 모델을 바꾸는 순간 모자가 머리에 박힌다 |
| 치수는 **캐릭터 전체 바운딩 박스**로 잰다 | 뼈·빈 노드는 메시가 없어 박스가 **비어 있다.** 소켓 박스로 재면 아이템이 0 배율이 돼 사라진다 |
| 부모는 소켓, 치수는 루트 | 애니메이션을 따라가려면 부모는 뼈여야 한다 |
| 소켓의 회전·스케일을 되돌린다 | 안 하면 아이템이 뒤틀린다 |

🔴 **남은 한계** — 바운딩 박스 꼭대기는 **머리 꼭대기가 아니다.** 곰은 귀가, 사람은 머리카락이
더 높다. 그래서 모자가 살짝 뜬다. **`D4` 사양에 「소켓 이름」뿐 아니라 「아이템별 오프셋」도
넣어야 한다.** 규약이 90%를 해결하고 나머지 10%는 에셋 사양이 들고 있어야 한다.

## 아직 안 한 최적화

- `gltf-transform` 으로 **텍스처 임베드 + Draco/Meshopt 압축 + KTX2** — 지금은 텍스처가

- 캐릭터 GLB 를 화면에 하나만 쓰는데 **애니메이션 32종이 다 들어 있다.** 쓰는 것만 남기면 준다

### 걸렸던 것

- **kit 마다 텍스처가 다르다.** 각 GLB 가 `Textures/colormap.png` 를 상대 경로로 참조한다.
  카테고리 폴더마다 그 kit 의 colormap 을 넣어야 한다. 하나로 합치면 색이 섞인다
- **원본 스케일이 kit 마다 다르다.** 카탈로그의 `size`(최대 변 길이)로 통일하고
  `loadProp` 이 바닥에 앉힌다. 안 하면 침대가 아바타보다 커진다

### 🔴 문서에 아직 안 반영한 것

이번 확장은 **`STR-005`(별의 옷장 외 목적지)** 그 자체다. 그 태스크의 착수 조건이
**「현금 분리선 재검토 통과 확인 — 미통과 시 착수 불가」** 인데 **재검토를 하지 않았다.**

방향은 `P-21` 안쪽이다 — 앱 내 재화일 뿐 현물·현금·제휴처가 아니다. 화면에도 적어 뒀다
(*"별은 방 아이템으로만 바꿀 수 있어요. 돈으로 바꾸지는 않아요"*). 다만 **절차를 건너뛴 것은 사실**이다.

`D4` 도 함께 바뀐다 — 「동물 종수 · 의상 벌수」에서 **「펫 종수 · 카테고리별 아이템 수 · 가격표」** 로.

### 방 꾸미기 모드

방 아래 **「🛠 방 꾸미기」** 버튼으로 들어간다. 보기 모드와 조작이 다르다.

| | 보기 | 꾸미기 |
| --- | --- | --- |
| 끌기 | 방이 돈다 | **아이템이 따라온다** |
| 누르기 | — | 아이템을 고른다 (바닥에 초록 링) |
| 버튼 | 「방 꾸미기」 | 왼쪽·오른쪽 회전 · 처음으로 · 다 꾸몄어요 |

- 아이템을 고르면 문구가 바뀐다 — *"「고양이」를 골랐어요 · 끌어서 옮기기"*
- 바닥 반지름 4.4 밖으로는 못 나간다
- 배치는 `localStorage` 에 남는다. 🔴 **프로토타입 전용** — 본 개발에서는 서버가 갖는다
- 아무것도 안 고르고 끌면 방이 돈다. 아이가 실수로 아이템을 못 옮기게

### 🔴 검증 방법이 하나 늘었다 — `tools/verify_room_drag.py`

**스크린샷으로는 「끌어서 옮기기」가 되는지 알 수 없다.** 헤드리스는 클릭을 못 한다.
그래서 크롬을 디버깅 포트로 띄우고 **CDP `Input.dispatchMouseEvent` 로 진짜 드래그**를 넣는다.

판정은 두 가지가 다 성립해야 통과다 — **아이템이 선택되고**, **`localStorage` 배치값이 바뀐다.**
실제로 고양이를 `(1.25, 1.35)` → `(-1.43, -1.2)` 로 옮기고 저장되는 것을 확인했다.

## 2026-08-31 (3) — 겹침 해결 · 위로 얹기

**같은 자리에 아이템을 놓으면 서로 파고들었다.** 이제 위로 얹힌다.

### 규칙

| | |
| --- | --- |
| 얹힐 높이 | 자기 **발자국(XZ 바운딩 박스)** 과 겹치는 것들 중 **제일 높은 윗면** |
| 겹침 판정 | 발자국을 **0.82배로 줄여서** 본다 — 스치기만 해도 얹히면 답답하다 |
| 펫 | **받침으로 쓰지 않는다** — 고양이 위에 케이크가 올라가면 이상하다. 펫 자신은 얹힐 수 있다 |
| 끄는 중 | 실시간으로 올라간다. 자기보다 높이 뜬 것은 받침에서 뺀다(되먹임 방지) |
| 놓을 때 | **방 전체를 다시 정렬**한다 — 받침을 치우면 위의 것이 내려온다 |
| 되돌리기 | 「↓ 바닥에」 버튼 — 얹힌 것만 활성 |

낮은 것부터 확정해 나가면 순환이 생기지 않는다. `y` 도 배치에 함께 저장한다.

## 2026-08-31 (4) — 실제 면 짚기 · 아이템 표시

### 얹힐 높이를 레이캐스트로 바꿨다

발자국(XZ 바운딩 박스) 겹침으로 재던 방식은 **어디에 걸치든 같은 높이**를 줬다.
침대 위에 고양이를 올리면 머리판 높이(`y=1.133`)로 떠서, 매트리스 위가 아니라 공중에 앉았다.

이제 **위에서 아래로 쏘아 실제로 닿는 면**을 찾는다.

| | |
| --- | --- |
| 짚는 곳 | 가운데 + 발자국 네 귀퉁이 **다섯 점** (아이템 회전 반영) |
| 고르는 값 | 다섯 점 중 **제일 높은 면** — 가운데만 보면 가장자리에 걸친 물건이 뜬다 |
| 받침 후보 | 잡을 때의 밑면 높이보다 **낮은 것만**. 잡은 물건 위에 얹혀 있던 것에 다시 올라타지 않는다 |
| 방 회전 | 광선 원점을 `room.localToWorld` 로 옮긴다. 아래 방향은 그대로다 |

같은 조작에서 `y` 가 **1.133 → 0.786** 으로 내려갔고, 가장자리로 밀면 `0.756` 으로 또 달라진다.
**자리에 따라 높이가 달라지는 것**이 발자국 방식과의 차이다 — 검사기가 이 차이를 본다.

### 아이템 표시

| | |
| --- | --- |
| 3D 이름표 | 꾸미기 모드에서만. three 위에 **평범한 DOM** 을 얹고 프레임마다 위치만 바꾼다 |
| 왜 DOM 인가 | React 상태로 올리면 매 프레임 리렌더가 돌아 방이 버벅인다 |
| 목록 칩 | **가려진 아이템의 우회로.** 아바타 뒤 책상처럼 3D 로 못 집는 것을 칩으로 고른다 |
