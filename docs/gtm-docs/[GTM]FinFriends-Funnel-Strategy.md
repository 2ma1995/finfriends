**근거 문서:** 핀프렌즈 PRD v1.0 (페르소나 · 여정 · 지표) · 기술 중립판 SRS (수용 기준 · 인용 제약)

## 0. 이 문서가 답하는 것

**랜딩 페이지에 무엇을 어떤 순서로 두는가, 그리고 왜 그 순서인가.**

퍼널은 일반론으로 짜지 않았다. **여정지도 10단계에서 감정이 가장 낮은 지점**을 찾아, 그 지점을
랜딩이 미리 처리하도록 설계했다.

---

## 1. 우리 퍼널이 보통과 다른 점 세 가지

| # | 보통의 SaaS 퍼널 | 핀프렌즈 |
| :-: | --- | --- |
| **1** | 방문자 = 사용자 | **방문자(보호자)와 사용자(아동)가 다르다.** 랜딩은 보호자만 읽는다 |
| **2** | 전환 = 결제 | **전환 = 카드 연결.** 구독이 없다(ADR-005). 유료 전환율을 지표로 쓰지 않는다 |
| **3** | 가입이 시작 | **가입 후 7일이 진짜 시작.** 아이가 실천을 한 건 해야 제품이 작동한다 |

> 그래서 랜딩의 목표는 「가입」이 아니라 **「아이가 첫 실천을 하는 데까지 데려가는 것」** 이다.

---

## 2. 대상 — 두 보호자

랜딩은 **두 사람을 동시에 설득해야 한다.** 둘은 같은 세그먼트(① 금융성장 증명형 · 29.3만명)에 있지만
**들어오는 문이 다르다.**

| | **H1 정미경** — 이미 쓰고 있다 | **H2 배성우** — 아직 아무것도 없다 |
| --- | --- | --- |
| 상황 | 경쟁 앱 8개월차 · 주 8,000원 충전 | 현금 봉투 3년 · 주 5,000원 |
| 불만 | *"숫자는 쌓이는데 확신은 안 쌓인다"* | *"볼 것이 아예 없다"* |
| **진입 후크** | 🌳 **성장 나무 · 월간 숲** | 📝 **계획 카드 · 계획↔실제 대조** |
| 최저 감정 지점 | **0단계** — 접하기 전 (누적 숫자가 증거가 못 됨) | **3단계** — 전환 결정 (현금 5초 vs 온보딩 5단계) |
| 진입 장벽 | **기록 이전 불가** — 8개월치가 사라진다는 체감 | **시간** — 가게 보면서 배송 받고 등록 |
| 이탈 트리거 | 나무 **2주 정체** → 아이 탓이 아니라 **앱 불신** | 확인할 게 없으면 **즉시** |

### 랜딩이 해야 할 일이 다르다

| | H1에게 | H2에게 |
| --- | --- | --- |
| 보여줄 것 | **나무 화면** — "이게 당신이 못 보던 것" | **대조 화면** — "이게 지금 아예 없는 것" |
| 미리 처리할 저항 | *"지금까지 쌓은 게 사라지나?"* | *"등록이 오래 걸리나?"* |

---

## 3. 퍼널 5단계

여정지도 10단계를 랜딩 관점으로 압축했다. **각 단계에 이탈 원인과 대응을 붙였다.**

```
① 도달 → ② 문제 인식 → ③ 차이 이해 → ④ 진입 결정 → ⑤ 첫 실천
                                          ↑ 가장 많이 새는 곳
```

| 단계 | 방문자 상태 | 랜딩이 하는 일 | 이탈 원인 | 대응 |
| :-: | --- | --- | --- | --- |
| **①** 도달 | *"용돈 앱 뭐 쓰지"* | 한 문장으로 무엇인지 | 무슨 서비스인지 3초 안에 모름 | 히어로에 **나무 화면 실물** |
| **②** 문제 인식 | *"우리 애도 그런가?"* | **누적 숫자 ≠ 성장 증거** 를 보여줌 | 남 얘기로 읽힘 | H1·H2 각각의 문장 병렬 |
| **③** 차이 이해 | *"다른 앱과 뭐가 다르지"* | **실천 없이는 안 자란다** | 기능 나열로 읽힘 | **화면 하나로** 증명 |
| **④** 진입 결정 | *"근데 귀찮은데"* | 장벽 두 개를 먼저 깬다 | **온보딩 부담 · 기록 이전** | **무료 · 나눠서 시작 · 「지금부터」** |
| **⑤** 첫 실천 | 가입 후 7일 | *(랜딩 밖)* — 앱이 담당 | 아이가 안 함 | 온보딩 첫 보상 5분 |

### 🔴 ④가 가장 많이 새는 곳이다

H2의 여정 감정이 **3단계(전환 결정)에서 1점**으로 최저다. 이유는 하나 —
**현금은 5초인데 온보딩은 5단계다.**

랜딩은 이 저항을 **결정 전에** 처리해야 한다.

| 저항 | 랜딩의 답 | 근거 |
| --- | --- | --- |
| *"돈 드나?"* | **보호자·아이 모두 무료** | ADR-005 |
| *"한 번에 다 해야 하나?"* | **나눠서 해도 됩니다** — 중간에 멈춰도 이어서 시작 | AC-8.1 재입력 0건 |
| *"카드 올 때까지 못 쓰나?"* | 배송 대기 중에도 **학습·별 획득 가능** | REQ-FUNC-015 |
| *"쓰던 기록은?"* | **「지금부터」 프레임** — 이전을 약속하지 않는다 | REQ-FUNC-017 Won't |

> **마지막 항목이 중요하다.** 기록 이전은 **하지 않기로 확정**(Won't Have)됐다. 랜딩에서 암시하면
> 가입 직후 실망으로 이어진다. *"지금부터 쌓입니다"* 로 정직하게 쓴다.

---

## 4. 🔴 랜딩에 쓸 수 없는 말

SRS §1.4의 **인용 금지 10항목**이 그대로 적용된다. 마케팅 문구는 여기서 가장 자주 깨진다.

| ✗ 쓰면 안 되는 말 | ✓ 대신 |
| --- | --- |
| *"소비 순간 알림이 갑니다"* · *"매장에 들어가면 알려줍니다"* | *"가기 전에 적고, 쓴 뒤에 맞춰봅니다"* — **자동 개입은 폐기된 기능이다** |
| *"아이가 성장했습니다"* | *"설계상 그렇게 되도록 만들었습니다"* |
| *"다른 앱은 확인 기능이 없습니다"* | *"확인은 됩니다. 그게 성장인지 알 수 없는 것이 문제입니다"* |
| *"금융만 다루는 유일한 앱"* | 검증 전이다(A1 미검증). **실천 연결**을 앞세운다 |
| *"WPA 55% 달성"* 등 목표 수치 | **기준선은 실측 전이다.** 숫자를 성과로 쓰지 않는다 |
| *"유료 전환율"* · 구독 언급 | **무료다.** 카드 연결이 전환이다 |

> **가장 위험한 것은 첫 줄이다.** 「소비 순간 개입」은 매력적이라 카피에 자꾸 들어온다.
> 그 기능은 **없다**(ADR-002). 쓰면 거짓 광고다.

## 5. 랜딩 페이지 구성

위 퍼널을 그대로 섹션으로 옮긴다.

| # | 섹션 | 퍼널 단계 | 핵심 |
| :-: | --- | :-: | --- |
| **1** | 히어로 | ① | 한 문장 + **나무 화면 실물**. *"배운 걸 실제로 했는지, 한 눈에"* |
| **2** | 문제 | ② | 누적 숫자 3개 vs 성장 증거. **H1·H2 두 문장 병렬** |
| **3** | 해법 — 나무 | ③ | **실천 없이는 안 자란다.** 화면 하나로 증명 |
| **4** | 해법 — 계획↔실제 | ③ | 쓰기 전에 적고, 쓴 뒤에 맞춰본다. **두 갈래** |
| **5** | 4영역 | ③ | 벌기 · 잘 쓰기 · 모으기 · 불리기 |
| **6** | 진입 장벽 해소 | ④ | **무료 · 나눠서 · 지금부터 · 카드 없이도 시작** |
| **7** | 안전 | ④ | 위치정보 미수집 · 법정대리인 동의 · 별↔현금 분리 |
| **8** | CTA | ④ | **「무료로 시작하기」** — 단일 행동 |

### 섹션 3·4가 이 랜딩의 전부다

나머지는 보조다. **화면 두 개로 두 가지 차별점을 증명**하지 못하면 다른 섹션이 아무리 좋아도 전환되지 않는다.

## 6. 측정

랜딩 자체 지표와 제품 지표를 **섞지 않는다.**

| 구간 | 지표 | 목표 | 비고 |
| --- | --- | :-: | --- |
| ①→② | 스크롤 2섹션 도달률 | — | **기준선 없음** — 실측 후 설정 |
| ③ | 화면 영역 체류 시간 | — | 섹션 3·4가 이 랜딩의 핵심 |
| ④ | CTA 클릭률 | — | |
| ④→⑤ | **가입 완주율** · 3단계 이탈률 | **≤ 30%** | AC-8.3 — 제품 지표 |
| ⑤ | **7일 내 첫 실천 인정률** | **≥ 60%** | O4 · E4 — 제품 지표 |
| 수익 | **카드 연결률** | 미정 | 검증과제 ⑥ 후 역산 |

> ⚠️ **위 목표값은 실측 전이다.** 랜딩 지표는 아직 기준선조차 없다. 달성한 성과처럼 쓰지 않는다.

## 7. 이 문서의 한계

정직하게 남긴다.

| 한계 | 내용 |
| --- | --- |
| **랜딩 지표에 기준선이 없다** | 제품 지표(O1~O14)와 달리 랜딩 퍼널은 측정한 적이 없다. §6은 **무엇을 잴지**만 정한 것이다 |
| **A/B 테스트 계획이 없다** | 트래픽이 없어 지금은 설계할 수 없다 |
| **H1의 「기록 이전」 저항은 완전히 해소되지 않는다** | 이전을 하지 않기로 확정했으므로 **프레임을 바꾸는 것이 최선**이다. 일부 이탈은 감수한다 |
| **아동은 랜딩을 읽지 않는다** | 아동 동기는 전적으로 앱 안(옷장·별)에서 만들어진다. 랜딩이 할 수 있는 일이 없다 |
