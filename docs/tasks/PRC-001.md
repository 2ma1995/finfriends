## ✅ Task Breakdown (실행 계획)
- [ ] 보호자의 미션 조건·금액 **사전 설정**
- [ ] 완료 → PENDING → APPROVED / REJECTED 상태 전이
- [ ] 승인 시 ⭐1 지급 + 실천 카운트 가산
- [ ] **거절 시 ⭐ 미지급 + 사유 표시**, 실천 카운트 미가산
- [ ] 아동 화면에서 「대기 중」·「승인되지 않음」을 **「미실천」과 시각적으로 구별**
- [ ] `approval_state_changed` 이벤트 적재

## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 거절이 미실천과 구별된다
- Given: 보호자가 미션을 거절한 상태에서
- When: 아동 화면을 열면
- Then: **「승인되지 않음 + 사유」** 가 표시되고 「미실천」과 색·문구가 다르다 (ACE-6.1)

Scenario 2: 대기가 미실천과 구별된다
- Given: 승인 대기 건이 있는 상태에서
- When: 아동 화면을 보면
- Then: 「대기 중」이 시각적으로 구별된다 (AC-6.3)
