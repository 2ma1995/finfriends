## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 동의 전 진입이 100% 차단된다
- Given: 동의가 미완인 계정에서
- When: 아동 화면 진입을 시도하면
- Then: **100% 차단**되고 `consent_gate_blocked` 가 적재된다 (REQ-NF-008)

Scenario 2: 실패 흐름 — 세션 만료 후 재개
- Given: 온보딩 중 세션이 만료된 상태에서
- When: 재로그인하면
- Then: 직전 완료 단계에서 재개하되 **동의 단계는 재확인**한다 (ACE-8.2)

Scenario 3: 실패 흐름 — 클라이언트 우회 시도
- Given: 클라이언트 상태를 조작해 아동 경로를 직접 호출하면
- When: 서버가 요청을 받으면
- Then: **서버 판정으로 거부**된다. 차단 건수가 계측된다
