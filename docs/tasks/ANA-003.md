## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 재연결 후 60초 내 반영된다
- Given: 아동 기기가 오프라인인 상태에서 실천을 완료하고
- When: 재연결되면
- Then: **⭐ 중복 지급 0건** · 반영 **≤ 60초** · 주차 귀속은 `client_ts` 기준 (ACE-2.1)

Scenario 2: 실패 흐름 — PWA 미승인
- Given: PWA 구성이 승인되지 않은 상태에서
- When: 요구사항을 검토하면
- Then: **온라인 전용으로 축소**하고 ACE-2.1을 폐기한다는 결정이 문서에 남아 있다 (§4.2)
