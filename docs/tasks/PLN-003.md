## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 지킨 날에만 별이 붙는다
- Given: 실제 결제액이 계획 금액 이하인 상태에서
- When: [확인했어요]를 누르면
- Then: **⭐1 지급** · `plan_met=true` · `star_granted=true` (AC-5.3)

Scenario 2: 넘긴 날도 회고는 제시된다
- Given: 실제 결제액이 계획을 초과한 상태에서
- When: [확인했어요]를 누르면
- Then: 회고 문장은 동일하게 제시하되 **⭐ 미지급**이고 **보유 별을 차감하지 않는다** (AC-5.4)

Scenario 3: 업종만 다르면 별은 지급된다
- Given: 금액은 계획 이내이고 업종만 다른 상태에서
- When: 대조 화면을 만들면
- Then: **⭐1을 지급**하되 회고를 「업종 다름」 갈래로 분기한다 (ACE-4.2 · ADR-008)

Scenario 4: 실패 흐름 — 회고 큐 적체
- Given: 회고 미완 상태에서 다음 소비가 발생하면
- When: 아동이 앱을 열면
- Then: 큐에 순서대로 제시되고 **3건 초과 시 「요약 회고」로 병합**된다 (ACE-5.2)
