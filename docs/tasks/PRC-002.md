## ✅ Task Breakdown (실행 계획)
- [ ] 완료 시점 기준 소급 지급 — **성공률 100%**
- [ ] 완료 시점 주기 종료 시 `BACKFILLED` 분기
- [ ] **나무 조건은 완료 시점 주기에 귀속** · 다음 주기 미가산
- [ ] 월간 숲 스냅샷 반영 + "지난 달 실천으로 인정됐어요" 표시
- [ ] 보호자 화면에 **「승인 대기 N건」** 노출

## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 48시간 후 승인도 소급된다
- Given: 미승인 48시간이 경과한 상태에서
- When: 보호자가 승인하면
- Then: 완료 시점 기준으로 ⭐가 지급되고 **성공률 100%** (AC-6.1)

Scenario 2: 종료된 주기로 귀속된다
- Given: 완료 시점 주기가 종료된 뒤 승인하면
- When: 소급이 실행되면
- Then: ⭐는 지급하되 **나무 조건은 주기 N에 귀속**되고 N+1에 가산되지 않는다 (ACE-6.2)

Scenario 3: 실패 흐름 — 대기가 미실천으로 오독되지 않는다
- Given: 승인 대기 건이 있는 상태에서
- When: 보호자가 성장 나무를 열면
- Then: **「승인 대기 N건」** 이 표시되어 반대 결론을 막는다 (AC-6.2)
