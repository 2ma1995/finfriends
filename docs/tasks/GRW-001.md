## ✅ Task Breakdown (실행 계획)
- [ ] 승급 조건 = 학습 이수 ∧ 퀴즈 정답 ∧ **실천 횟수**의 논리곱
- [ ] 실천 0건이면 나머지 초과 충족해도 **미승급**
- [ ] 영역별 주기 — 벌기·잘 쓰기·모으기 **매달**, 불리기 **적금 시작~만기**
- [ ] 주기 초기화 배치 연동 (`/api/cron/cycle-reset`)
- [ ] `tree_state_changed` 이벤트 적재 (단계 전후·조건·정체 일수)
- [ ] 미충족 시 남은 조건을 **조건별로 각각** 산출

## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 퀴즈만으로는 자라지 않는다
- Given: 학습만 완료하고 실천 0건인 아동이
- When: 퀴즈를 추가로 풀어 조건을 초과 충족하면
- Then: **나무 단계가 상승하지 않고** "실천 N회 남음"이 표시된다 (AC-2.2)

Scenario 2: 남은 조건이 조건별로 보인다
- Given: 실천은 충족하고 학습·퀴즈가 미충족인 상태에서
- When: 나무를 열면
- Then: **승급하지 않고** 남은 조건이 각각 표시된다 (ACE-2.3)

Scenario 3: 영역마다 주기가 다르다
- Given: 달이 바뀐 상태에서
- When: 네 영역을 조회하면
- Then: 벌기·잘 쓰기·모으기는 초기화되고 **불리기는 유지**된다 (§6.2.1)
