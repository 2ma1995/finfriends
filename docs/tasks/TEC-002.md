## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 인증 없는 호출이 존재를 드러내지 않는다
- Given: 시크릿 헤더 없이
- When: Cron 엔드포인트를 호출하면
- Then: **404** 를 반환한다. 401·403으로 존재를 알리지 않는다

Scenario 2: 재실행이 무해하다
- Given: 동일 `run_key` 로
- When: 배치를 두 번 실행하면
- Then: 부작용이 **1회만** 발생한다 (REQ-TEC-011)

Scenario 3: 주기가 요건을 만족한다
- Given: 미접속 판정 작업이 등록된 상태에서
- When: 스케줄을 확인하면
- Then: **4시간 주기**이며 6시간 요건을 만족한다 (§6.3)
