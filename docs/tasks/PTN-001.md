- Given: 잔액이 있는 카드를 해지하면
- When: 해지 플로우를 완료하면
- Then: **전액 환불**된다 (REQ-NF-013 · P-11)

Scenario 2: 실패 흐름 — 외부 API 실패
- Given: 카드 발급 API가 실패한 상태에서
- When: 오류가 반환되면
- Then: 입력값이 **24시간 보존**되고 사용자 언어로 사유가 표시된다 (ACE-8.1)
