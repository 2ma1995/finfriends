## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 불일치가 즉시 드러난다
- Given: 원장에 인위적 불일치를 주입한 상태에서
- When: 정산 배치를 실행하면
- Then: **즉시 알림**이 발생하고 30분 내 확인 대상으로 표시된다

Scenario 2: 정상 시 조용하다
- Given: 불일치가 없는 상태에서
- When: 배치를 실행하면
- Then: 알림이 발생하지 않고 결과만 기록된다. **오탐 0건**
