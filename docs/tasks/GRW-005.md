## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 60초 내 3개를 지목한다
- Given: 전월 데이터가 있는 상태에서
- When: 달라진 점을 찾게 하면
- Then: **60초 이내 3개 이상 지목 ≥ 6/8** · 확인 소요 중위 **≤ 3분** (AC-1.3)

Scenario 2: 잔액 0에도 성과가 보인다
- Given: 별을 즉시 소진해 잔액이 0인 계정에서
- When: 숲을 열면
- Then: **「이번 달 획득 별」이 스크롤 없이 노출** ≥ 6/8 (AC-1.4)

## ⚙️ Technical & Non-Functional Constraints
- 성능: 숲 p95 ≤ 2,000ms (REQ-NF-001).
- 디자인: 확인 소요 중위 ≤ 3분이 목표다 — 정보를 늘리면 목표가 멀어진다.
- 프로토타입: 이 화면은 **MCK-001 목 픽스처**로 먼저 만든다(전월 델타 7항목 · 전월 데이터 없음). 백엔드 선행이 완료되면 **목을 즉시 교체**하고, 목이 남아 있는 동안 완료로 표시하지 않는다 (제안 `docs/plan-docs/prototype-suggestion.md` §6).
