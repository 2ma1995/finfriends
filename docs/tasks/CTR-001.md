## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 유효 입력이 타입 안전하게 통과한다
- Given: 액션 입력 스키마가 정의된 상태에서
- When: 유효 입력을 파싱하면
- Then: `z.infer` 타입과 런타임 결과가 일치하고 반환이 `ActionResult` 다. **tsc 경고 0건**

Scenario 2: 실패 흐름 — 무효 입력이 스택을 노출하지 않는다
- Given: 필수 필드가 빠진 입력이 주어지고
- When: 검증이 실행되면
- Then: 예외를 던지지 않고 `{ ok:false, code, message }` 를 반환한다. 스택·SQL·내부 경로가 응답에 없다

Scenario 3: 실패 흐름 — 아동 식별정보 필드 부재
- Given: 전체 입력 스키마가 정의된 상태에서
- When: 키 집합을 검사하면
- Then: 위치 좌표·얼굴 이미지에 해당하는 필드가 **0개**다 (REQ-TEC-009)
