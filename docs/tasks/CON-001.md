## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 아동은 독립 로그인이 불가능하다
- Given: 아동 프로필이 존재하는 상태에서
- When: 자체 자격증명으로 로그인을 시도하면
- Then: **경로 자체가 없다.** 인증 로그의 독립 로그인 시도 **0건** (REQ-NF-011)

Scenario 2: 실패 흐름 — 보호자 세션 만료
- Given: 아동 화면 사용 중 보호자 세션이 만료되면
- When: 다음 요청이 발생하면
- Then: 아동 화면이 **잠기고** 보호자 재인증을 요구한다

## ⚙️ Technical & Non-Functional Constraints
- 보안: 아동 계정은 보호자 계정에 **종속**된다. 외부 공유·친구 기능 없음 (중립판 §1.2).
- 기술 제약: **C-TEC-003** 범위의 Supabase Auth를 쓴다.
