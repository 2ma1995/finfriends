## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 매핑이 양방향으로 성립한다
- Given: 제휴사 업종 코드가 주어진 상태에서
- When: 내부 분류로 변환하면
- Then: **미매핑 코드 0건**이거나 「그 밖」으로 안전하게 떨어진다

Scenario 2: 실패 흐름 — 상세도 부족 감지
- Given: 업종 코드가 단일 값으로만 오는 상태에서
- When: 매칭 정확도를 산출하면
- Then: **90% 미만이 즉시 드러나** 금액 단독 판정 축소 결정(ADR-008)을 검토할 수 있다
