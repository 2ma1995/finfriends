## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 단일 배포 단위
- Given: 저장소를 클론한 상태에서
- When: 빌드 산출물과 배포 대상을 확인하면
- Then: 배포 단위가 **1개**이고 독립 서버 프로세스가 **0개**여야 한다 (REQ-TEC-001)

- Given: 운영 환경에 `CRON_SECRET` 이 없는 상태에서

- Then: **빌드가 실패**하고 누락 키 이름이 로그에 나온다. 런타임까지 미루지 않는다

- Given: 코드에 API 키 문자열이 포함된 상태에서

- Then: 검사가 **실패**한다 (REQ-TEC-013)
