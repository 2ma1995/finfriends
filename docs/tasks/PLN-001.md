## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 업종이 대조 가능한 값으로 저장된다
- Given: 계획 카드를 작성한 상태에서
- When: 저장 결과를 확인하면
- Then: 업종이 **승인 데이터와 대조 가능한 코드**로 기록되고 작성 주체가 남는다 (AC-4.1)

Scenario 2: 작성률이 산출된다
- Given: 운영 4주가 경과한 상태에서
- When: 작성률을 집계하면
- Then: `plan_card_created ÷ payment_settled` 로 산출되고 **≥ 50%** 를 판정할 수 있다 (AC-4.4)

## ⚙️ Technical & Non-Functional Constraints
- 설계: **ADR-002** 자동 발동은 없다. 대외 문구에 「소비 순간 알림」을 쓰지 않는다.
- 생존 조건: 작성률 < 30%면 사전 절반이 비고 **사후 대조까지 무너진다**.
