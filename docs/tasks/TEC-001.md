## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 위반이 빌드를 멈춘다
- Given: 5종 각각의 위반 픽스처가 있는 상태에서
- When: `prebuild` 를 실행하면
- Then: **5건 모두 빌드를 실패**시키고 위반 파일·심볼을 출력한다

Scenario 2: 정상 코드는 통과한다
- Given: 위반이 없는 저장소에서
- When: `prebuild` 를 실행하면
- Then: 5종 전부 통과하고 **오탐 0건**이다

Scenario 3: 실패 흐름 — 기능 플래그 우회 차단
- Given: 전환 경로를 플래그로 감싼 코드가 있는 상태에서
- When: 금지 심볼 검사를 실행하면
- Then: **여전히 실패**한다. 플래그는 켜질 수 있으므로 경로 자체가 없어야 한다 (ADR-003)

## ⚙️ Technical & Non-Functional Constraints
- 기술 제약: **C-TEC-007** — 외부 CI를 쓰지 않는다. 차단은 **Vercel 빌드 단계**에서 일어난다 (ADR-T08).
- 성능: 검사 시간이 길면 개발이 느려진다. 전체 **30초 이내** 목표.
