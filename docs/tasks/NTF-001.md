## 🧪 Acceptance Criteria (BDD/GWT)

Scenario 1: 시간대 조정이 반영된다
- Given: 보호자가 야간 수신을 설정한 상태에서
- When: 알림이 발생하면
- Then: **설정한 시간대에 발송**되고 열람률이 계측된다 (AC-7.3)

Scenario 2: 실패 흐름 — 권한 차단
- Given: 보호자가 푸시를 차단한 상태에서
- When: 알림이 발생하면
- Then: **푸시 실패로 기록하지 않고** 앱 내 배너 경로로 넘긴다 (§6.5)
