| --- | --- |
| 🔴 별은 **승인에서만** 생긴다 | 「했어요」(`markDone`)는 `doneAt` 만 찍는다. `grantStar` 는 `approveMission` 안에만 있다. 아이 쪽 액션에서 원장을 건드리지 않는다 — 건드리면 아이가 별을 무한히 만든다 |
| 🔴 중복 지급 0건 | 멱등키가 `mission:<id>` **하나**다. 두 번 눌러도 `P2002` 로 막힌다 (REQ-NF-006) |
| 🔴 소급이 다음 주기를 부풀리지 않는다 | `cycleId` 는 **「했어요」 시점**에 박힌다. 승인은 이 값을 고치지 않는다 (ACE-6.2) |
| 🔴 「승인 대기」 ≠ 「미실천」 | 아이 화면이 세 구역으로 갈린다 — 오늘 할 수 있는 것 / 기다리는 중 / 지난 미션. 거절은 사유를 그대로 보여준다 (AC-6.2) |
| 🔴 결합 조회 차단 유지 | `missions.child_id` 는 `identity` 로 **FK 를 걸지 않았다**. `activity` 역할로는 아이 이름을 못 읽는다 (REQ-NF-009 · S3) |

**FK 를 안 건 대가** — 아이 행을 다시 만들면 미션이 **고아**로 남는다. 실제로 공유 개발 DB 에서
한 번 발생했다. 개발용으로 `app/prisma/seed-missions.mjs` 를 뒀다 — 아무것도 지우지 않고
현재 아이에게 미션만 다시 깐다. **운영에서는 아이 삭제 시 `activity` 정리 작업이 따로 필요하다 (미구현).**

**검증** — 실제 DB 대상 한 바퀴 전건 통과.

```
① 미실천 → ② 「했어요」: 잔액 그대로 (별 안 붙음)
③ 승인 1회 +2 · 2회째 P2002 거부 → 순증가 = 보상 (중복 0건)
④ 대기 중 되돌리기 성공  ⑤ 승인된 것 되돌리기 0건 (막힌다)
```

🔴 **아직 안 한 것** — 부모의 **미션 만들기** 화면이 없다. 지금은 시드로만 생긴다.

## D12 ⚪ 아이는 성장 나무를 보지 않는다

| 항목 | 내용 |
| --- | --- |
| SRS | 성장 나무의 열람 주체가 명시돼 있지 않다 |
| 결정 | **보호자 전용** (2026-08-31 사용자 결정) |
| 실제 | 아이 화면 10개 중 나무를 보여주는 화면이 **하나도 없다**. `/parent/tree` · `/parent/forest` 뿐이다 |

**왜** — 나무는 **보호자가 아이의 변화를 읽는 장치**다(UX-001). 아이에게 보이면
「나무를 키우려고 실천한다」가 되어 실천의 동기가 지표로 옮겨간다. 아이 쪽 동기는 별과 방 꾸미기다.

> 방에 놓는 「작은 나무」 아이템(`room.fixture.ts`)은 **성장 나무가 아니다.** 그냥 장식이다.

## D13 🟠 아이 온보딩이 없었다 — 아이는 설명을 들은 적이 없다

| 항목 | 내용 |
| --- | --- |
| SRS | 보호자 온보딩 6단계(CON-003)만 있다 |
| 실제 | **아이 쪽 온보딩이 없다.** 기기 토큰으로 열면 곧장 방이 나온다 |
| 결과 | `/child/welcome` 7장 + `activity.child_onboarding` (`20260831000009_child_onboarding`) |

**왜 이게 필요한가** — 아이는 가입 흐름을 거치지 않는다(S5). 보호자가 기기를 등록해 주면
**아무 안내 없이 방 한가운데 떨어진다.** 특히 「했어요」를 눌러도 별이 바로 안 붙는다는 것을
모르면 아이는 **고장 났다고 느낀다** — AC-6.2 가 화면에서 「승인 대기」와 「미실천」을
구별하라고 요구하는데, 그 구별의 **뜻을 아무도 아이에게 알려 주지 않았다.**
4장(미션)에서 이 한 줄을 먼저 말해 둔다.

**설계에서 지킨 것**

| 규칙 | 어떻게 |
| --- | --- |
| 🔴 별만 받아 갈 수 없다 | `advanceTour` 가 **한 칸씩만** 올린다. `finishTour` 는 요청 숫자가 아니라 **DB 의 step** 을 본다. URL `?step=6` 도 본 데까지로 깎인다 |
| 🔴 별은 한 번뿐 | 멱등키 `onboarding:<childId>` 하나. 다시 보기를 몇 번 해도 `P2002` 로 막힌다 (REQ-NF-006) |
| 🔴 아이를 가두지 않는다 | 건너뛰기가 항상 열려 있다. 건너뛰면 홈이 **다시 붙잡지 않는다** — 못 빠져나가는 화면이 첫 경험이 되면 안 된다 |
| 🔴 나무를 말하지 않는다 | 7장 어디에도 성장 나무가 없다 (D12) |
| 진행을 서버에 둔다 | 아이 기기는 초기화될 수 있다. `localStorage` 는 남지 않는다 — 중간에 닫아도 본 데까지 이어서 본다 |

**실제 값을 문장에 넣는다** — 「지금 네 별은 9개야」 · 「지금 할 수 있는 미션이 3개 있어」.
남의 이야기로 읽히면 설명이 아니라 광고가 된다.

**끝내면 별 1개** — `ONBOARDING_LEARN`. 이 트리거는 SRS 에 **이미 정의돼 있었고 쓰는 곳이 없었다.**
여기가 그 자리다.

**검증** — 실제 DB 대상 전건 통과.

```
① 첫 진입 step 0  ② to=6 요청 → 1칸만 (앞지르기 차단)
③ 끝까지 6/6      ④ 끝내기 +1  ⑤ 다시 끝내기 P2002 거부 → 순증가 1
⑥ step 0 에서 끝내기 → TOO_EARLY (막힘)  ⑦ 건너뛴 뒤 홈이 다시 안 보냄
```

🔴 **아직 안 한 것** — 읽어 주기(음성)가 없다. 저학년은 글을 못 읽을 수 있다.
이모지와 짧은 문장으로 버티고 있지만 **접근성 요건으로 다시 봐야 한다.**
