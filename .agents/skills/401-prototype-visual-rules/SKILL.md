# 로컬 시각 프로토타입 화면 규범

**단일 원천은 `docs/plan-docs/[Spec]Prototype-Visual-Plan.md` 다.** 이 스킬은 그 문서에서
**어기기 쉬운 것만** 뽑아 둔 것이다. 값이 필요하면 명세를 직접 읽는다.

## 범위

로컬 프로토타입만 해당한다 — `INF-001` `INF-002` `UX-001` `UX-002` `UX-004` `UX-006` `MCK-001` `GRW-003` `GRW-005` `PLN-004` 의 **부분 착수**다.
범위 정의는 `docs/plan-docs/prototype-local-scope.md`.

**전부 부분 착수다.** 명세에 없는 화면·요소·기능을 추가하지 않는다.
필요해 보이면 만들지 말고 `docs/grill/GRILL_LEDGER.md` 에 토픽으로 올린다.

## 화면은 3종 · 상태는 6종이다 (명세 §1)

**화면** — `P1` 성장 나무 · `P2` 계획↔실제 대조 · `P3` 월간 숲
**상태** — `F1` 정상 · `F2` 실천 0건 · `F3` 정체 14일 · `F4` 첫 달 · `F5` 계획 넘김 · `F6` 승인 대기

- **4번째 화면 · 7번째 상태를 만들지 않는다.**
- **아동 홈을 만들지 않는다** — 아바타 에셋이 D4 미결이다.
- 3×6 매트릭스에 **빈칸을 만들지 않는다.** 모든 칸에 무언가가 있다(명세 §1.3).

## 실천 근거는 기본 노출이다 (명세 §2.1 슬롯 ⑤)

| 어기기 쉬운 것 | 규칙 |
| --- | --- |
| 「자세히」로 접어 둔다 | ❌ — **펼치지 않아도 보인다**. 접으면 *"나무가 자랐다 = 실제로 했다"* 가 읽히지 않는다 |
| 정체 원인을 하나만 쓴다 | ❌ — **전부** 표시하고 **가장 적게 남은 것을 최상단**에 둔다 |
| 조건부 슬롯 자리에 빈 줄을 남긴다 | ❌ — ③정체·④대기는 조건부다. 없으면 자리도 없다 |
| 나무 단계를 확정 사양처럼 쓴다 | ❌ — **D6 미결이다.** 화면에 「예시값」을 표시한다 |

**왜 지켜야 하는가** — AC-1.2가 *"진행자 개입 0회로 「실천」에 도달 ≥ 6/8"* 을 건다.
근거가 접혀 있으면 보호자는 **퀴즈를 많이 풀어서**라고 답한다. 그러면 AC 실패다.

## 넘긴 날은 벌칙이 아니다 (명세 §2.2)

| 어기기 쉬운 것 | 규칙 |
| --- | --- |
| 경고색·오류색을 쓴다 | ❌ — **테라코타**(`--clay`)다. 조정 사실이지 잘못이 아니다 |
| 별 차감·회수를 표현한다 | ❌ — **차감하지 않는다**(P-03). *"가진 별은 그대로예요"* |
| 넘김에서 회고 문장을 생략한다 | ❌ — **똑같이 제시한다.** 갈리는 건 별뿐이다 |
| 아이에게 이유를 고르게 한다 | ❌ — **[확인했어요] 한 번**이 전부다 |

**왜 지켜야 하는가** — 확인만 해도 별을 주면 참은 날과 안 참은 날이 같아지고,
**나무와 숲이 거짓 신호**를 보낸다. 반대로 벌을 주면 회고 자체를 피하게 된다.

## 빈 화면은 델타 0이 아니다 (명세 §1.3 · §3.2)

| 어기기 쉬운 것 | 규칙 |
| --- | --- |
| 첫 달에 `0% → 0%` 로 그린다 | ❌ — **「다음 달부터 비교할 수 있어요」** 로 대체한다 |
| 실천 0건에 흰 화면을 둔다 | ❌ — 안내 + **다음 행동**을 준다 |
| 빈 화면에 사과한다 | ❌ — *"아직 없어요"* + 무엇을 하면 되는지 |

**왜 지켜야 하는가** — 0으로 그리면 보호자는 **「변화가 없다」로 읽는다**(ACE-1.2).
이 제품은 초기에 화면이 오래 비어 보이므로(ADR-006의 대가), **빈 화면이 첫인상이다.**

## 획득 별은 스크롤 없이 (명세 §2.3)

월간 숲의 **「이번 달 획득 별」은 스크롤 없이 보여야 한다**(AC-1.4).
별을 즉시 소진하는 아이에게 **유일한 누적 증거**다. 아래로 밀면 존재하지 않는 것과 같다.

## 용어 고정 (명세 §2.4)

| 쓴다 | 쓰지 않는다 |
| --- | --- |
| **실천** | 활동 · 미션수행 · 참여 |
| **별** | 포인트 · 코인 · 스타 |
| **계획 카드** | 예산 · 한도 · 리밋 |
| **부모**(화면) / **보호자**(문서) | 학부모 · 양육자 |

문구 · 변수명 · 주석 전부 해당한다.

## 항상 걸리는 것

- **판정형 문구 금지** — *"잘했어요"* 같은 평가 대신 **사실**을 적는다
- **아이 탓으로 돌리지 않는다** — 정체는 **조건**의 문제다 (AC-3.2 오귀인 ≤ 2/8)
- **아이가 이해할 수 있는 말** — 법정 의무다 (REQ-NF-014 · P-12)
- **shadcn/ui 자체 구현 금지** (D-08 · REQ-TEC-007) — 인벤토리 7종에 있으면 그것을 쓴다
- **목은 한 곳에** — `src/mocks/` 밖으로 새지 않는다. 교체 지점이 흐려진다
