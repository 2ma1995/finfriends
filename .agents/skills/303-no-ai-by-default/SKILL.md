# AI는 기본적으로 쓰지 않는다

**요구사항 35건 중 AI 호출을 요구하는 항목은 0건이다.**

C-TEC-005(Vercel AI SDK) · C-TEC-006(Gemini)은 *"AI 호출 기능이 포함된 경우"* 라는 **조건부 조항**이며,
현 판본에는 **적용 대상이 없다.** REQ-TEC-015로 **유보 등록**만 돼 있다.

---

## 1. AI로 만들고 싶어지는 지점과 실제 설계

| 만들고 싶어지는 것 | 실제 설계 | 근거 |
| --- | --- | --- |
| 회고 문장 생성 | **사전 작성 문장 풀에서 비복원 추출** | 중립판 §6.3 규칙 11 · ACE-5.1 |
| 아바타 이미지 생성 | **사전 제작 에셋** (Lottie) | P-13 · 생성형 AI 미사용 |
| 계획↔실제 업종 매칭 | **업종 코드 사전 대조** | DAT-004 · 정확도 ≥ 90% |
| 정체 원인 문구 | **조건 단위 규칙 기반 표시** | AC-3.1 · ACE-3.1 |
| 학습 콘텐츠 | **콘텐츠 원고**(외부 선행 D3) | REQ-FUNC-003 |

**전부 결정론이다.** 아동 대상 서비스이고 지표가 문장 재노출률까지 세므로, 생성 결과의 변동이
**측정 자체를 흔든다.**

## 2. 그래도 AI가 필요해 보이면

**만들지 않는다. 사람에게 묻는다.**

요구사항에 없는 기능이므로 SRS를 먼저 고쳐야 한다. 순서는 이렇다.

1. 어느 요구사항을 위해 필요한지 특정한다
2. 그 요구사항이 **정말 AI 없이는 안 되는지** 확인한다 — 위 표의 다섯 항목은 전부 결정론으로 성립했다
3. 사람에게 제안한다. **코드를 먼저 쓰지 않는다**

## 3. 도입이 결정됐다면 — 그때 지킬 것

| 규칙 | 내용 |
| --- | --- |
| SDK | **Vercel AI SDK 표준 인터페이스만** 사용한다. 벤더 SDK 직접 호출 금지 |
| 모델 | **Google Gemini 기본.** 모델 ID는 `AI_MODEL` **환경 변수로만** — 코드 상수 금지 |
| 교체 | **환경 변수 교체만으로 모델이 바뀌어야** 한다. 분기 코드를 두지 않는다 |
| 서버 | **자체 추론 서버를 두지 않는다.** Route Handler에서 외부 API를 호출한다 |
| 🔴 문구 검수 | 아동에게 노출되는 생성물은 **REQ-NF-014 알기 쉬운 언어 검수를 생성 파이프라인에 적용**한다. 법정 의무다 |
| 폴백 | LLM은 **폴백**이다. 결정론 경로가 먼저 있어야 한다 |
| 비용 | 호출 비용은 `C_child` 에 들어간다(REQ-NF-016). 원가 임계에 반영한다 |

## 4. 환경 변수는 이미 자리를 잡아 뒀다

```
AI_MODEL                          # 미사용
GOOGLE_GENERATIVE_AI_API_KEY      # 미사용
```

**자리가 있다고 써도 된다는 뜻이 아니다.** 도입 결정 전에는 비워 둔다.
