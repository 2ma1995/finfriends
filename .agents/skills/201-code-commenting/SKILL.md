# 주석

## 1. 원칙

**코드가 말하는 것을 반복하지 않는다.** 주석은 **왜 이렇게 했는지**를 적는 자리다.

```
❌ // 별을 1개 지급한다
   grantStar(childId, 1)

✅ // 계획 준수 시에만 지급한다 — 확인만 해도 주면 참은 날과
   //  안 참은 날이 같아져 나무·숲이 거짓 신호를 보낸다 (v13 §5-3)
   if (result === "MET") grantStar(childId, 1)
```

## 2. 반드시 주석을 다는 곳

| 대상 | 무엇을 적나 |
| --- | --- |
| **규제 제약** | 근거 조항 — `P-21` · `REQ-NF-009` 처럼 |
| **비직관적 선택** | 왜 자연스러운 방법을 쓰지 않았는지 |
| **불변값** | 왜 0%·100%인지 (아동이 모은 것을 잃는 경험) |
| **역산 상한** | 어느 AC에서 나온 값인지 |
| **미해소 결정** | `D-01` · `D-02` · `D-03` 이 걸린 지점 |
| **예외 등록** | Lottie처럼 제약의 예외인 것 |

## 3. 요구사항 ID를 남긴다

```ts
// REQ-NF-008 · P-05 — 아동 화면은 첫 진입부터 개인정보 처리가
//  시작되므로 순서 자체가 규제 요건이다. 클라이언트 판정 금지.
await assertConsented(guardianId)
```

**ID가 있으면 나중에 왜 그런지 문서에서 찾을 수 있다.**

## 4. 하지 말 것

- 주석으로 코드를 비활성화하지 않는다 — 지운다. 이력은 git에 있다
- TODO를 남기지 않는다 — 태스크로 만든다
- **거짓 주석을 남기지 않는다** — 코드를 고치면 주석도 고친다
