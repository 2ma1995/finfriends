# 기술 제약 가드레일

**이 스킬의 목적은 하나다** — 기술적으로 더 나은 대안을 **조용히 들이는 것을 막는 것**.

제약은 발주 측이 확정했다. 우회가 필요하면 **사람에게 묻는다.** 판단을 혼자 내리지 않는다.

---

## 1. 추가하기 전에 이 표를 본다

| 하려는 것 | 판정 | 대신 |
| --- | :-: | --- |
| Redis · Memcached 등 캐시 서버 | ❌ | Next.js 캐시 + PostgreSQL |
| Kafka · RabbitMQ 등 메시지 큐 | ❌ | DB 큐 테이블 |
| 별도 백엔드 서버 · 상시 워커 | ❌ | Server Action · Route Handler |
| 모듈 간 내부 HTTP 호출 | ❌ | `modules/<m>/index.ts` 함수 직접 호출 |
| **Vercel Cron Jobs** | ❌ | **Supabase `pg_cron` + `pg_net`** (ADR-T02) |
| cron 데몬 · 외부 스케줄러 | ❌ | 동일 |
| GitHub Actions 등 외부 CI | ❌ | **`prebuild` 게이트** — Vercel 빌드가 실패한다 |
| 다른 ORM · 쿼리 빌더 | ❌ | Prisma |
| 다른 UI 컴포넌트 킷 | ❌ | shadcn/ui (`npx shadcn add`) |
| shadcn 컴포넌트 직접 재구현 | ❌ | `npx shadcn add` |
| 코드에 모델 ID · 시크릿 상수 | ❌ | 환경 변수 |
| **AI 호출 코드** | ❌ | **스킬 `303-no-ai-by-default` 를 읽는다** |

## 2. Vercel Cron을 쓰지 않는 이유

가장 자주 잘못 권해지는 항목이다. Next.js에 스케줄러가 없으니 Vercel Cron이 자연스러워 보인다.

**무료 요금제가 일 1회다.** 미접속 알림은 발송 지연 `p95 ≤ 6시간` 을 요구하므로 성립하지 않는다.
`pg_cron` 은 **C-TEC-003 범위 안**이라 스택을 넓히지 않으면서 4시간 주기를 만든다.

```
Supabase pg_cron → pg_net → POST /api/cron/<job>   (X-Cron-Secret · 불일치 시 404)
```

**배치 로직은 Next.js에 그대로 남는다.** 스케줄만 DB가 담당한다.

## 3. 라이브러리 추가 절차

1. **위 표를 먼저 본다.** 걸리면 거기서 멈춘다
2. 걸리지 않으면 — 이것이 **요구사항을 구현하는 데 필요한가**, 아니면 편의인가
3. 필요하다면 `package.json` 에 추가하기 전에 **`prebuild` UI 의존성 검사**에 걸리는지 확인한다
4. **예외는 명시적으로 등록한다** — 현재 등록된 예외는 **Lottie 1건**(아바타 렌더러 · ADR-T05)뿐이다

## 4. 제약이 요구사항을 실제로 깨뜨릴 때

**우회하지 말고 기록한다.**

1. `docs/tech-design-docs/[SRS]FinFriends-SRS-Tech-v1_0.md` **§8 제약 충돌 해소 대장**을 읽는다
2. 이미 기록된 항목인지 확인한다 — **X1~X6 · Y1~Y7**에 13건이 있다
3. 없으면 **사람에게 묻는다.** 대장에 추가하는 것은 사람의 판단이다

### 이미 기록된 충돌 — 다시 논의하지 않는다

| # | 무엇이 깨졌나 | 채택안 |
| :-: | --- | --- |
| X1 | 웹 푸시가 iOS 미설치 보호자에게 도달하지 않음 | 발송 **시도** 100% · 도달률 별도 집계 |
| X2 | Tailwind·shadcn은 3D 렌더러가 아님 | **Lottie 2.5D** |
| X3 | 서버 렌더 웹앱에 오프라인 쓰기 큐 없음 | Serwist + Dexie |
| X4 | Next.js에 스케줄러 없음 | **`pg_cron`** |
| X5 | 앱 밖 알림 채널 없음 | Webhook 1개 (**D-02 미해소**) |
| X6 | 본인인증 고정 IP 요구 | 제휴사 위임 (**D-03 미해소**) |

## 5. 자주 나는 착각

| 착각 | 사실 |
| --- | --- |
| *"CI 게이트가 필요하니 GitHub Actions를 쓰자"* | `prebuild` 스크립트가 **Vercel 빌드를 실패**시킨다. C-TEC-007과 충돌하지 않는다 |
| *"모듈을 나눴으니 서비스로 분리하자"* | 모듈은 **배포 단위가 아니라 경계**다. 배포 단위는 1개 |
| *"성능을 위해 캐시 서버를 붙이자"* | 서버 컴포넌트 + 캐시가 기본값이다. 상한 초과는 **재설정 트리거**로 다룬다 |
| *"AI로 회고 문장을 생성하면 좋겠다"* | 요구사항에 없다. 문장은 **사전 작성 풀에서 비복원 추출**한다 |
