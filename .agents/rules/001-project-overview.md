# 001 — 프로젝트 개요

## 무엇을 만드는가

**핀프렌즈** — 아동이 배운 금융 지식을 실제 돈 행동으로 잇고, 그 변화를 보호자가 읽을 수 있게 하는 서비스.

## 두 가치 선언

모든 요구사항은 이 둘 중 하나에 귀속된다.

| 선언 | 내용 | 누구의 것 |
| :-: | --- | --- |
| **①** | 아이에게 **성장이 일어난다** (학습 → 실천) | 아동 |
| **②** | 그 성장이 보호자에게 **보인다** (실천 → 변화의 증거) | 보호자 |

**①이 ②의 전제다.** 아이가 실천하지 않으면 보호자 화면은 거짓말을 하지 않고 **비어 있을 뿐**이고,
그 빈 화면이 *"우리 애가 안 하는구나"* 로 읽힌다. 그래서 북극성 지표는 ①에 걸려 있다.

## 북극성 지표 — WPA

**주간 실천 인정 아동 비율.** 분자·분모가 조작적으로 정의돼 있다.

```
분자 — 주차 내 「실천 트리거」로 ⭐를 1회 이상 받은 아동 수
분모 — 동의 완료 ∧ 계정 7일 경과 ∧ 직전 28일 내 세션
제외 — 학습 경로 트리거(온보딩 학습·출석·퀴즈)는 분자에 넣지 않는다
```

**학습 경로를 분자에 넣으면 접속만으로 지표가 올라 활동량 지표로 퇴화한다.**

## 4영역

학습 · 나무 · 실천이 공유하는 **고정 분류**다. 늘리거나 줄이면 세 곳이 함께 바뀐다.

| 상수 | 표기 | 실천 경로 | 주기 초기화 |
| --- | --- | :-: | --- |
| `EARN` | 💰 벌기 | 개통 | **매달** |
| `SPEND` | 🛒 잘 쓰기 | 개통 | **매달** |
| `SAVE` | 🐷 모으기 | 개통 | **매달** |
| `GROW` | 🌱 불리기 | **미개통** | **적금 시작~만기** |

## 설계를 지배하는 네 가지 규칙

| 규칙 | 내용 |
| --- | --- |
| **실천 없이는 자라지 않는다** | 나무 승급은 학습 ∧ 퀴즈 ∧ **실천**의 논리곱. 실천 0건이면 나머지를 초과 충족해도 승급 불가 |
| **모은 것은 잃지 않는다** | 별은 주기 초기화가 없고, 계획을 넘겨도 **차감하지 않는다**. 정합성 오류율 0% |
| **빈 화면은 안내한다** | 실천 0건 · 전월 데이터 없음 — **델타 0으로 렌더하지 않고** 안내 문구로 대체 |
| **동의가 먼저다** | 법정대리인 동의 완료 전 아동 화면 진입 불가. **순서 자체가 규제 요건** |

## 제품이 하지 않는 것

| 항목 | 이유 |
| --- | --- |
| **소비 순간 자동 개입** | **폐기된 기능**(ADR-002). 로드맵에도 없다. 사전 수단은 **계획 카드**뿐 |
| **위치정보 수집** | 요건을 회피한 것이 아니라 **요건이 발생하지 않는 구조** |
| 앱 외부 현금 · 친구 기능 · 모의투자 · 미션 사진 인증 | 범위 결정 |
| 아동 대상 유료 구독 | 보호자·아동 모두 무료(ADR-005) |
| **AI 호출** | 요구사항 0건. 회고 문장은 사전 작성 풀에서 비복원 추출 |

> 🔴 대외 문구에 *"소비 순간에 알림이 간다"* 를 쓰지 않는다. **사실이 아니다.**
